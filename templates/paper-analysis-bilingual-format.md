# 固定论文双语分析格式

默认采用六章双语结构；用户可指定其他语言、研究体裁或模板。

- 新论文填写模板：`templates/paper-analysis-bilingual.md`；版本 `paper-analysis-bilingual-1`。
- 适用于本工作区今后的论文分析、中文阅读笔记与 Obsidian 论文整理；用户明确要求其他格式时按该次要求执行。
- 开始分析前读取填写模板；六个章节的标题与顺序保持一致。分析篇幅与证据卡数量按论文内容调整，不照搬其他论文的事实、编号顺序、数值或核验声明。
- 保留 YAML 字段、阅读范围 info callout、一句话理解，以及 C/E/R/I/S 编号体系。正文以中文分析、英文原文 quote callout、中文对译、来源与边界说明逐条对应。
- 保留公式阅读卡、数据与实验条件、结果的作者报告/核对/证据边界、作者局限与分析者推导、研究建议与关联；无材料或不适用时明确说明，不凭空补齐。
- 引文依法控制长度，不复制参考稿中的大段引文。来源绑定实际页码/章节/图表/公式；仅有 HTML 时写真实 URL 与章节，不虚构 PDF 页码或 SHA256。
- 区分 paper_fact / reasoned_interpretation / ai_suggestion；证据编号可追溯；无独立语义复核时保持 Unverified。不复制“已核对”等未经执行的声明。
- 元数据来自真实 Zotero 条目；缺少身份时保留空值并注明待关联，不编造 key。保留原标签，不建立未经确认的双链。
- 最后保留机器区结束标记和 My Notes。Vault 写入仍须 SafeWriter、保存计划、完整批准哈希和回读；已有笔记须 reviewed_update 与编辑器静默确认。
- 元数据占位预览不算完成论文分析；现有简略 analysis-note-plan 渲染不满足此格式时不得将其直接当作最终交付。
- 本规则不自动重写历史笔记；用户要求重整时再生成符合模板的计划，遵守已有内容保护。

## 论文标题命名

- 论文笔记的文件名（去掉 .md）、正文唯一一级标题和 YAML `title` 统一使用完整原文论文标题，优先采用 Zotero 原始 `title`；保留大小写、标点和副标题，不以简称、中文译名或 Zotero key 替代。中文译名保留在 `title_zh`。路径分隔符等文件名确实不允许的字符只在文件名中做最小替换并记录；H1 与 title 保留原题。

- 所有文献／论文笔记直接保存在 `配置的 Vault 研究根目录` 根目录，不为论文新建或使用 `Papers/`、`Research/` 或按论文划分的子文件夹。与完整原文论文标题命名规则同时生效；现有笔记迁移须保持稳定身份、分析正文及 My Notes，并同步 Registry。测试专用 `_validation/` 和系统目录不属于文献笔记，不纳入迁移。

说明：以随附填写模板为结构依据；领域信息由配置和研究问题提供。

## 跨学科使用

实验、公式和代码不是所有研究的必要组成。理论论文记录定义、假设与推导；定性研究记录材料、取样、编码及解释依据；观察研究区分相关、混杂与因果主张。不适用或未报告项明确说明，不能补成虚假实验。原文为非英语时按实际语言引用；中文对译和双语格式按用户需求调整。
